# レイアウト / 作画指示用紙アプリ

アニメのレイアウト・作画指示用紙を作成する React アプリです。

## 起動方法

```bash
npm install      # 初回のみ
npm run dev      # 開発サーバー起動 → http://localhost:5173
```

本番ビルドは `npm run build`（出力先 `dist/`）、確認は `npm run preview`。

## 機能

1. **16:9 画像貼り込みゾーン**
   - 「🖼 画像を選択」またはゾーンをタップ／クリックして画像を読み込み。
   - ゾーン内を **ドラッグで移動**。拡大縮小は **ピンチ（iPad）** または **マウスホイール（PC）**。ダブルタップで位置・倍率をリセット。
2. **周囲へのコメント追加**
   - 「💬 コメント追加」で付箋を作成。用紙は画像ゾーンより広く、周囲の余白に配置可能。
   - 付箋は **バーをドラッグで移動 / 右下つまみでリサイズ / 5色から色変更 / 📎で画像添付 / ×で削除**。
3. **右下の尺・コマ数記入欄**
   - 「尺（秒＋コマ）」「コマ数」を記入。
4. **PNG / PDF 保存**
   - 「⬇ PNG保存」「⬇ PDF保存」で用紙全体をそのままキャプチャして書き出し（A4 横 相当）。
   - iPad では共有シート、または「開く」から写真アプリ等へ保存できます。

起動時に用紙を画面へ合わせます。ツールバーの「画面に合わせる」で再フィット。iPad は横向きが使いやすいです。 `npm run dev` は同一 Wi-Fi の iPad から `http://<PCのIP>:5173` でも開けます。

上部にヘッダー欄（作品名・シーン・カット・作画）もあります。
ツールバー部分はキャプチャ対象外で、白い用紙のみが保存されます。

## 技術構成

- React 18 + Vite
- `html-to-image`（画面キャプチャ）
- `jspdf`（PDF 出力）
